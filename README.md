# Typocalypse

A work in progress Unity 2d arcade game that involves typing. In order to escape a zombie apocalypse, you must type to move your character, dodging zombies and obstacles and reaching as high of a score as possible. You can duel a friend online and see who can survive longer and get a higher score. All the art and SFX were created by me.

Overall, a passion project to help make practicing touch typing fun and to improve my programming skills.
